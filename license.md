### What that means in practice

"Larger Work" is a defined term and has nothing to do with how big anything is.
Section 1.7 defines it as a work combining Covered Code with code not governed
by this License — so **a game built on this engine is a Larger Work**, whether
it took a weekend or five years.

Not requiring it there means: **if you build a game on Fluxion, you do not have
to show anything.** The attribution above is owed only by someone who ships the
engine itself, or a modified version of it, as a program with a user interface.
For an engine that is a narrow case, and it is meant to be — the requirement is
there for whoever passes the engine on, not for whoever builds with it.

Section 14(b) also caps what may ever be demanded, and this project may not ask
for more than it: one copyright notice naming the Original Developer, one phrase
of at most ten words, one graphic image, and one URL. Where a program shows
attribution for other parties as well, this project's attribution must be no
less prominent than theirs.

Section 14(a) limits itself further: where access to the software creates no
graphical user interface at all — a dedicated server build, a command-line
tool — the obligation does not apply.
